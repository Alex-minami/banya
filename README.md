# Баня в Краснокаменке

Статический сайт бани: парная, банщик, отдельная комната отдыха с PS4, кинопроектором и музыкой.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages**.
В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, затем **Save**.

Сайт не требует сборки или установки зависимостей. Пути к ресурсам относительные и поддерживают размещение по адресу проекта GitHub Pages.

## Файлы

- `index.html` — содержание страницы.
- `style.css` — оформление и адаптация для телефонов.
- `script.js` — меню, анимации и копирование координат.
- `assets/` — изображения и локальные шрифты; информация о лицензиях шрифтов в `FONT-LICENSES.txt`.

Иллюстрации показывают визуальную концепцию атмосферы, а не фотографии реальной бани.
